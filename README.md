# How much stage structure is needed to model population dynamics?

> **Archived repository.** This repository is no longer updated. Development
> now takes place in the single canonical
> [`r-R0-pop`](https://github.com/ferdi-p/r-R0-pop) repository, which remains
> private during manuscript review and will be made public before publication.
> A versioned analysis package will also be preserved in Zenodo.

This repository contains the Python code and processed input data supporting
the manuscript “How much stage structure is needed to model population
dynamics? A case study of an invasive fruit fly.” The analysis uses
temperature-dependent life-history data for *Drosophila suzukii* (spotted wing
drosophila).

The repository compares three nested models:

- **M1:** one state for each juvenile stage and one adult state;
- **M2:** juvenile stage chains and one adult state;
- **M3:** the M2 juvenile chains plus an adult exit chain with
  age-dependent fecundity.

Manuscript source files are intentionally not included. All tables, diagnostic
reports, and figures generated by the code are written under `outputs/`, which
is ignored by Git.

## Reproduce the analysis

Python 3.12 or newer is required. The exact environment used for verification
is recorded in `requirements-lock.txt`.

```bash
make setup
make verify-model
```

`make verify-model` runs the tests, rebuilds the complete model workflow, and
checks that the expected datasets, numerical summaries, and figures were
produced. A typical rebuild takes about one minute on a laptop.

For subsequent runs:

```bash
make model        # rebuild the model analyses, tables, reports, and figures
make analysis     # model workflow plus raw-data summary plots
make test         # run the unit tests only
make help         # list the supported entry points
```

The Makefile uses `.venv/bin/python` when that environment exists and sets
`PYTHONPATH=src`. Individual scripts also provide `--help`.

## Repository contents

| Path | Contents |
|---|---|
| `src/r_r0_pop/` | Demography, life-history fitting, stage-chain models, and plotting utilities |
| `scripts/` | Reproducible analysis entry points |
| `tests/` | Unit tests for data handling, demography, precision, and population models |
| `data/processed/baser/` | Tidy CSV inputs used directly by the analysis |
| `outputs/` | Rebuildable results; created locally and not version controlled |

The principal entry points are:

| Analysis | Script |
|---|---|
| Process raw workbooks (optional) | `scripts/preprocess_baser_data.py` |
| Direct life-table demography | `scripts/calculate_baser_direct.py` |
| M1--M3 fitting and comparison | `scripts/compare_model_complexity.py` |
| Mortality interventions | `scripts/analyze_mortality_interventions.py` |
| Adult-substage fecundity profile | `scripts/plot_m3_fecundity_profile.py` |
| Input/output consistency checks | `scripts/verify_outputs.py` |

## Data source

The tracked CSV files are direct transformations of the life-table and
fertility data from Baser et al. If you use these data, please cite:

> Baser, N., Rossini, L., Anfora, G., Temel, K. M., Gualano, S., Garone, E.,
> and Santoro, F. (2025). Thermal Development, Mortality, and Fertility of an
> Apulian Strain of *Drosophila suzukii* at Different Temperatures. *Insects*,
> 16, 60. [https://doi.org/10.3390/insects16010060](https://doi.org/10.3390/insects16010060)

The original workbooks and scripts are available from the
[source-data repository](https://github.com/lucaros1190/DSuzukiiLifeTables).
They are not duplicated here because the processed CSV files are sufficient to
run this analysis. See `data/processed/baser/README.md` for provenance details.
